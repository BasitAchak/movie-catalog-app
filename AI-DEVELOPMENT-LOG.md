# AI Development Log

## Project

ReelSpace — Movie & Series Discovery Application

## AI Assistance

AI was used as a development assistant throughout the project.

### Prompt 1 — Project Setup

I asked AI to guide me through creating a React application with Vite and installing the required dependencies.

### Prompt 2 — Firebase Authentication

I asked AI to implement Firebase email/password authentication and connect the React application to Firebase.

### Prompt 3 — Login Page

I asked AI to create a functional login page with email/password validation, loading states, and Firebase authentication.

### Prompt 4 — Movie Catalogue

I asked AI to create a movie catalogue with movie cards, search functionality, and favourite functionality.

### Prompt 5 — UI Redesign

I asked AI to redesign the application with a modern interface that was visually different from the reference application while maintaining the required functionality.

### Prompt 6 — Interactive Features

I asked AI to add genre filtering, favourites filtering, smooth scrolling, responsive design, loading states, and empty states.

## Manual Improvements

After reviewing the AI-generated implementation, I manually tested the application and made corrections and improvements.

Examples include:

1. Testing the Firebase login flow with the Firebase test account.
2. Checking that logout correctly returns the user to the login page.
3. Testing search and genre filtering.
4. Testing the favourite functionality.
5. Checking the layout at different screen sizes.
6. Reviewing the generated code and correcting issues where necessary.
